# Rodrigo Station · Currículum de Rodrigo Bartolomé

Proyecto de IPE (DAM): mi currículum en tres formatos que comparten los mismos datos (`js/data.js`).

- **`estacion.html`**: estación espacial 3D en tercera persona (Three.js) con seis salas: Puente de mando, Laboratorio, Núcleo de IA, Comunicaciones, Archivo de misiones y Hangar de operaciones.
- **`index.html`**: versión web clásica e interactiva.
- **`CV original de Rodrigo Bartolome.pdf`**: CV de una página, generado a partir de `cv.html`.

Controles de la estación: WASD para moverse, ratón para la cámara, E para interactuar, Esc para cerrar y R para volver al inicio. También se puede navegar por clics desde el panel «Navegación».
